# 旅帖（たびちょう）

**旅の思い出を積み重ね、日々の暮らしに彩りを添える旅行記録アプリ**

## 1. サービス概要

「旅帖（たびちょう）」は、旅先の写真や訪れた場所、そのときの思い出を記録・保存できる旅行記録アプリです。旅の計画や行きたい場所の管理にも対応し、旅の前から旅の後までをひとつにまとめられます。旅の思い出を積み重ねることで、日々の暮らしをより豊かに彩ることを目指しています。

## 2. 開発背景

旅行の写真を見返した際に、撮影した場所やそのときに感じたことを思い出せなかったり、いつ、どこへ行ったのかが曖昧になったりすることがありました。

こうした経験から、旅先での出来事や感じたことを写真とともに記録し、後から振り返ったときにも、そのときの情景や気持ちを思い出せるようにしたいと考え、「旅帖」を考案しました。

## 3. サービスへの思い

旅の記録は、訪れた場所や出来事だけでなく、一緒に過ごした人との思い出や交わした会話、心が動いた瞬間をよみがえらせてくれるものだと考えています。

「旅帖」を通して、記録を見返すたびに懐かしさや楽しさを感じ、旅の思い出が日々の暮らしに彩りを添えるようにしたいです。そして、思い出を振り返ることが「また旅に出たい」という気持ちにつながるサービスを目指しています。

## 4. ターゲットユーザー

旅行や写真を撮ることが好きで、旅の思い出を残し、後から振り返ることを大切にする人を主なターゲットとしています。特に、旅先での出来事や一緒に過ごした人との思い出を大切にしたい人を想定しています。

### 想定するユーザーの悩み

- 旅行先でたくさん写真を撮るものの、整理できずにスマートフォンに保存したままになっている
- 写真を見返しても、撮影した場所や当時の出来事、感じたことを思い出せない
- 一緒に過ごした人との思い出や会話を、記録として残しておきたい
- 過去の旅を振り返りながら、次の旅行先を考えたい

## 5. 主な機能【MVPリリース時】

- **ユーザー登録：** 氏名・メールアドレス・パスワードの登録のみで簡単に登録可能です。
- **ユーザーログイン：** メールアドレス・パスワードでログイン可能です
- **写真・思い出の記録：** 旅先の写真とともに、そのときの気持ちや出来事を記録します。登録した記録は、編集・削除が可能です。他のユーザーへの公開機能はなく、閲覧できるのは自分自身のみです。そのため、他人の反応を気にすることなく、自分自身が感じたその時の思いを自由に記載できます。また、一つの記録に登録できる写真は一枚のみです。（本リリース時には複数登録可能にする予定です。）
- **写真・思い出の一覧表示：** 登録した記録を一覧で表示できます。
- **写真・思い出の詳細表示：** 記録一覧画面で選択した記録の詳細を表示します。詳細表示画面では、記録登録時に記載した日時・場所・写真・感じた思いを確認できます。

## 6. サービスの特徴・差別化ポイント

### 自分だけの特別な記録空間

「旅帖」が目指すのは、人に見せるためではなく、自分自身のために旅の思い出を残せる場所です。

誰かに見せることを前提とせず、そのときに感じたことや考えたことを、思いのままに自分らしく記録できる体験を大切にしています。人に見せるために文章や写真を整える必要がなく、何気ない出来事や個人的な感情も自由に残せることを特徴とします。

記録を見返すことで、当時の情景や会話、気持ちがよみがえり、懐かしさや楽しさを感じられる。そして、その思い出が次の旅への意欲につながる。そんな体験を提供することを目指しています。

## 7. デザインコンセプト

植物標本や古い植物図鑑、旅の日記を思わせる、自然でどこか懐かしいデザインを目指しています。

- **カラー：** セージグリーン、オリーブ、生成りなど、自然を感じる落ち着いた色合い
- **モチーフ：** 葉や植物標本、旅の足跡、ノート
- **雰囲気：** 温かみがあり、穏やかで、長く使いたくなるデザイン
- **UI/UXの方針：** 思い出を気軽に記録でき、後から心地よく振り返れることを重視します。

## 9. 今後の展望（予定）【本リリース以降】

- **訪問先の記録：** 訪れた場所や位置情報を記録し、旅の足跡を残せるようにします。
- **旅の一覧・振り返り：** 過去の旅行記録を一覧で確認し、思い出を振り返れるようにします。過去の思い出を振り返るきっかけを提供します。
- **行きたい場所の管理：** 気になる場所を保存し、次の旅行の計画に役立てます。
- **旅の計画・管理：** 旅行前の計画と旅行後の記録をまとめて管理し、旅行の計画から記録、振り返りまでをよりスムーズにつなぎます。
- **過去の写真や記録の検索：** 過去の写真や記録を探しやすくします。
- **タグによる分類：** それぞれの記録をその時の感情や、場所の種類などによってタグ付けし、タグごとに整理、見返すことができるようにします。

今後は、記録のしやすさと振り返りやすさを両立し、旅の思い出を日々の暮らしの中で自然に楽しめるサービスへと発展させていきます。
